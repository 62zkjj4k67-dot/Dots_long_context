# Changelog

## 2.0.0 — 2026-11-02
- Merged the separate subject-area and project-management kits into one self-contained `SETUP.md`. The assistant now chooses **Topic**, **Project** or **Hybrid** mode from evidence and confirms it with the owner.
- Made the kit platform-agnostic: a capability check replaces product-specific steps, with a manual mode for assistants that cannot write files.
- Added standing session-start instructions and a context-handoff rule so work survives long or ended conversations.
- Added a one-file-per-event fallback for storage that cannot append safely.
- Generalized industry-specific terms into examples.
- Added README, privacy checklist and `.gitignore`.

## 1.0 — 2026-11-02
- Initial private preparation as two kits (subject area; project management).
